# Сайт SLM Design

`site/` содержит конфигурацию, тему и статические ресурсы VitePress.

Источником опубликованной документации служит [`DRAFT`](../DRAFT/index.md). Сайт включает Levels 1-2 и их правила; исследовательский каталог `DRAFT/level-3` исключён из маршрутов и поиска.

## Маршруты

- `/` - главная страница;
- `/level-1/` - документация Level 1;
- `/level-2/` - документация Level 2;
- `/rules/` - устройство правил;
- `/rules/level-1` - канонический реестр Level 1.
- `/rules/level-2` - канонический реестр Level 2.

## Локальный запуск

```bash
npm run docs:dev
```

## Проверка

```bash
npm run check:site
```

Команда проверяет реестр правил, собирает VitePress и проверяет опубликованные маршруты и якоря правил.
