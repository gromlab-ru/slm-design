# SLM Design

Этот каталог содержит действующую legacy-документацию по SLM-архитектуре.

Используй эту документацию как источник истины для задач по SLM Design: слоям, модулям, сегментам, публичному API, business factory, composition modules и монорепозиториям.

## Структура

- `canons/` - основные каноны SLM Design.
- `examples/` - дополнительные примеры реализации.

Точка входа: `canons/index.md`.
